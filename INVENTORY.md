# What we have (inventory)

A plain list of every piece in this kit today. To use it, follow [START-HERE.md](START-HERE.md).

## Tools

| Tool | Role in the kit | Cost to start |
|---|---|---|
| Google Drive | the one shared folder every helper reads and writes | free |
| Claude | careful writing, long files, works inside Drive | free plan |
| ChatGPT | all-rounder, voice chat | free plan |
| Gemini | Google's app, voice, images, calendar | free plan |
| Grok | what people say online right now | free plan |
| Manus | longer jobs that run on their own | free plan |
| Muse (Meta AI) | quick ideas, captions, second opinions | free plan |
| Vibe (Mistral) | other languages, questions about a document | free plan |

Limits and plans change. Current details: [FREE-MODELS.md](FREE-MODELS.md). Sign-up steps: [SIGNUP.md](SIGNUP.md).

## Kinds of helpers

| Kind | What it does | Where it is described |
|---|---|---|
| Chat helper | answers, drafts, money and client summaries, on request | [PLAYBOOK.md](PLAYBOOK.md) |
| Interviewer | asks you about your work, then writes a task list | [INTERVIEW.md](INTERVIEW.md) |
| Second opinion | reads another helper's file and checks it | [DRIVE-LAYOUT.md](DRIVE-LAYOUT.md) |
| Loop helper | works through its own to-do file, one item at a time | [LOOPS.md](LOOPS.md) |

Every helper follows the same talk-short rule ([README.md](README.md)) and asks before it pays, sends or deletes.

## Drive folders

| Folder | Who writes | What |
|---|---|---|
| `WORK-HQ/` | you | the one folder; holds `START-HERE.md` and `TASKS.md` |
| `BOOKS/` + `BOOKS/receipts/` | you (helpers draft) | money sheet, receipt photos by month |
| `CLIENTS/` | you | short client notes |
| `IDEAS/` | you and helpers | interview notes, ideas |
| `LOOPS/` | each loop helper, its own file | loop to-do files (marker word `WORKLOOP`) |
| `<app>/out/` | that app only | answers, drafts, reports |
| `_old/` | anyone | old files; nothing gets deleted |

Full map: [DRIVE-LAYOUT.md](DRIVE-LAYOUT.md).
